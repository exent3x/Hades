# Russian Roguelite v0.7 — карта похода

Эта версия продолжает v0.6.1, которая у тебя запускалась. Главный следующий шаг — не переделывать пока всю боёвку в 2.5D, а добавить отдельную карту маршрута, не зависящую от пользовательских C++-типов.

## Что нового

- После `ENTER` в хабе открывается карта из семи направлений.
- Открыт только **Чёрный лес**. Остальные шесть биомов намеренно заблокированы.
- Внутри Чёрного леса — ветвящийся маршрут из десяти этапов перед Лешим. На каждом этапе можно выбрать один из доступных узлов.
- Типы узлов: бой, элита, алтарь, тайник, событие и лечение.
- После боевой комнаты игрок выбирает награду, затем возвращается на карту и выбирает следующий путь.
- После прохождения десяти этапов открывается узел босса — Леший.
- Кнопка «Бросить поход» возвращает в хаб и сбрасывает временный билд.
- Пока карта или награда открыты, управление скрытым игроком отключается.
- `world_map.tscn` — отдельная маленькая сцена на обычном Godot `Control`; никаких пользовательских C++-типов внутри `.tscn` нет.

## Структура

- `project/scenes/main/main.tscn` — корень приложения.
- `project/scenes/world/hub.tscn` — убежище.
- `project/scenes/world/world_map.tscn` — карта биомов и маршрут Чёрного леса.
- `project/scenes/world/rooms/forest_room_01.tscn` и `forest_room_02.tscn` — боевые комнаты, которые переиспользуются на маршруте.
- `project/scenes/world/rooms/leshy_boss_room.tscn` — босс.
- `project/scripts/main.gd` — переходы между состояниями похода.
- `project/scripts/world_map.gd` — отрисовка карты и выбор узлов.
- `project/scripts/player.gd` — обёртка вокруг C++ игрока и включение/выключение игрового ввода.

## Управление

- `WASD` — движение.
- Мышь — направление атаки.
- `ЛКМ` — атака/комбо.
- `SPACE` — дэш.
- `Q` — огненный круг.
- `ENTER` в хабе — открыть карту похода.
- `U` в хабе — постоянное улучшение за 50 Вечной славы.

## Установка поверх исходника

Рекомендуется распаковать архив в новую папку, а из последней рабочей версии перенести только уже скачанный `godot-cpp/`.

```text
hades-rus-v07/
├── godot-cpp/        # перенести из рабочей версии
├── src/              # из этого архива
├── project/          # из этого архива
├── SConstruct
├── build_debug.bat
└── rebuild_debug.bat
```

Сборка из корня проекта:

```powershell
.\rebuild_debug.bat
```

Либо вручную:

```powershell
scons target=template_debug arch=x86_64
```

Открывай `project/project.godot` в Godot.

## Важно про 2.5D

В v0.7 я пока не перевожу боевые комнаты на 3D: это потребовало бы одновременно менять перемещение, коллизии, камеру, слои окружения и hitbox/hurtbox. Следующий безопасный этап после проверки карты — подготовить общий `Actors`/Y-sort слой, визуальную глубину и перспективные стены, не меняя базовые механики. Затем можно переводить отдельную тестовую комнату, сохраняя остальные 2D сцены рабочими.

## v0.8 — тестовая 2.5D-арена (Леший)

Основная 2D-игра не тронута. Добавлено отдельное 3D-окружение для проверки подхода «спрайты-билборды в 3D-мире»:

- `src/player/player_controller_3d.*` — `PlayerController3D` (CharacterBody3D): WASD по плоскости XZ, прицел мышью через луч камеры в пол, комбо ×3, дэш, огненный круг (Q). Логика и числа перенесены из `PlayerController`, единицы: пиксели / 60 = метры.
- `src/enemies/boss_controller_3d.*` — `BossController3D`: 900 HP, 3 фазы (скорость/урон/радиус растут, оттенок спрайта меняется), круговая атака с телеграфом.
- `project/scripts/billboard_util.gd` — спрайт-билборд (ноги в точке 0,0,0), мягкая тень, диски-индикаторы.
- `project/scripts/player3d.gd`, `boss3d.gd` — обёртки (строят коллизии/хитбоксы/спрайт и создают C++-ядро через ClassDB, как в 2D).
- `project/scripts/arena3d.gd` + `scenes/test3d/arena3d.tscn` — арена: пол, стены, наклонная камера (~55°, FOV 35), HUD.
- `project/art/sprites/` — `player_hero.png`, `leshy_boss.png` (фон вырезан).

Запуск: пересобрать (`rebuild_debug.bat`), в хабе нажать **T**. Либо открыть `arena3d.tscn` и F6. `R` — рестарт, `ESC` — назад.

## v0.9 — новая механика Лешего на тестовой 2.5D-арене

Босс (`BossController3D`) теперь машина состояний: выбор способности → замах с телеграфом → применение → восстановление.
Сам он ничего не создаёт: просит сигналом `spawn_requested`, а `arena3d.gd` + `world_factory.gd` собирают объекты.

Способности Лешего:
- **Корни** (`HazardZone3D`, kind=root): 4/6/8 штук по фазам, часть ложится вокруг героя. Урон 14 + оглушение 1.2 с, если наступить (дэш — прыжок через корень). Живут 6 с. Пока есть корни — Леший не двигается.
- **Удар рукой с елью**: дуга ~65° на 3.4 м, 28 урона, телеграф-прямоугольник. Только пока ель в руке; не начинается, пока герой оглушён.
- **Бросок ели** (`Projectile3D`, kind=spruce): навесом в точку, 32 урона. Затем ель торчит в земле — Леший идёт за ней (×1.5 скорости) и без неё не бьёт рукой. Спрайт меняется на `leshy_boss_nospruce.png`.
- **Рой птиц** (kind=birds): 1/2/3 зоны ≥5 м от Лешего, 7 урона каждые 0.5 с, без оглушения.
- **Приспешники** (`MinionController3D`): 2–3 лешонка, максимум 4 одновременно.
- **Грибы** (kind=mushroom): выращиваются у героя или (с фазы 2) бросаются навесом; через 1.2 с взрыв: 16 урона, замедление −35% на 4 с, ослабление −30% урона героя на 6 с.
- **Сужение арены** (с фазы 2): до 62% размера на 9–12 с; герой и враги зажимаются внутри, края закрывают колючие заросли.

Герой: огненный круг заменён **метанием камня** (Q): прямой снаряд, 40 урона, перезарядка 1.8 с, бьёт Лешего и приспешников. Герой получил состояния: оглушение (иммунитет 0.7 с после), замедление, ослабление.

Баланс — константы в начале `boss_controller_3d.cpp` и в `execute_action()`.
