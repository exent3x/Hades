# v1.0 — 3D-модели, анимации, босс-файт в основной игре

Патч поверх v0.9: скопируйте папки `src/` и `project/` в корень проекта с заменой, пересоберите (`rebuild_debug.bat`)
и один раз откройте проект в редакторе Godot — он импортирует `art/models/hero.glb` и `leshy.glb`
(пока модели не импортированы, игра откатывается на спрайты-билборды).

## Что изменено
- Слои коллизий: слой героя (1) совпадал с маской босса/врагов (1), поэтому `move_and_slide()` босса выталкивал самого босса.
  Теперь герой на слое 16. Героя из тела босса выталкивает односторонний `push_out()`
  (`BossController3D::push_player_out`, `BODY_PUSH_RADIUS`, `BODY_PUSH_STIFFNESS`). Минионы выталкивают героя так же.
- Босс-файт в основной игре: `main.gd::_enter_boss()` запускает 3D-арену, билд героя (HP, урон, дэш) переносится в бой,
  итог приходит сигналом `fight_finished`. Клавиша T в хабе по-прежнему открывает арену отдельно.
- 3D-модели с анимациями (`model_visual.gd`). Герой: idle, walk, dash, stun, attack_1..3, throw, hit, death.
  Леший: idle, walk, melee, throw, cast, slam, grab, hit, death. Замах босса прокручивается по `get_windup_progress()`.
  Ель — отдельный меш: исчезает из руки при броске и летит как снаряд.
- Лес по краям арены, освещение под PBR-модели.

## Настройка
- Размер моделей: `MODEL_SCALE` в `player3d.gd` / `boss3d.gd`.
- Анимации: `tools/rigging/hero_anims.py`, `boss_anims.py`, затем `build_hero.py` / `build_boss.py`.
